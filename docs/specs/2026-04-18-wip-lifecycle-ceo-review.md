## 한줄 판정

엔지니어링은 탄탄하지만, 이건 **"재고관리 기능"이 아니라 "돈이 어디로 새는가"를 보여주는 기능으로 재프레이밍되어야 한다**. 기술적으론 A-, 시연 무기로는 C+.

| --------------------------- | ----------- | --------------------------------------------------------------------------- |
| Problem fit (진짜 문제인가) | 6           | 문제는 실재하나, KBI 경영진 top-3 pain 인지 근거 약함                       |

## Premise Challenges

### 1. "주 3-4회 재공실사 Excel 업로드" — 검증되지 않은 가정

설계서 전체가 올라선 premise. 제조업 현장 실사는 월 1회도 귀찮아하는 곳이 대부분. 시연 당일엔 PwC 가 데이터를 만들어 돌릴 수 있지만, **"배포 후 작동하려면 현장이 주 3-4회 실사해야 함"** 이 드러나는 순간 설득력 붕괴. 경영진의 "우리 현장에서 돌아가나?" 질문에 답 없음.

### 2. "재공 누적 → 원가낭비" = top pain? — 숫자 없음

케이블 제조업 실제 top pain: (1) 납기 지연 → 페널티 (2) 긴급수주 대응력 (3) 구리/알루미늄 가격 헷지 (4) 설비 가동률. **재공 수백m 누적의 연간 손실 규모가 설계서에 없음**. "시스템적으로 옳다" 와 "경영진이 아파한다" 사이 gap.

### 3. "T1↔T3 gap 2-3일" 이상적 가정

현실: run 주 1 (월요일), 긴급수주 불규칙, 실사 월말 → gap 2-3**주** 가 흔함. §3 는 이상적 운영만 상정.

### 4. "예상재공 매칭은 phantom inventory 위험 → Level 3 opt-in"

기술적으로 옳은 판단이나, **시연에선 이게 가장 직관적·강력한 기능**. "아직 안 만든 재공도 계획에 반영" 이 임원에게 훨씬 꽂힘. 주력 기능을 숨긴 꼴.

## 10-star 대안 탐색

### Alt-1 (강력 추천): "유휴 자본" 프레임 — 사용자 회계 강점 활용

사용자는 회계사. "재공 300m" 대신 **"유휴 자본 ₩420,000" (150SQ × 300m × 단가 ₩1,400/m)** 로 표시. 대차대조표에서 "재고자산 중 Dead Stock" 을 AI 가 실시간 계산. 경영진이 보는 건 m 가 아니라 **잠긴 돈**.

- 삼일PwC 임원 (= 회계 domain) 에게 즉시 꽂힘
- 사용자의 유일한 domain edge 를 활용하는 앵글
- **이 프레임 하나로 시연 가치 2x**
- 구현: 50 LOC (대시보드 카드 1개 + `GET /wip/dead-stock-value`)

### Alt-2 (병행 추천): "Dead Stock → 영업 추천"

300m 잉여가 DB 에 있으면 **영업팀에 "150SQ 300m 이하 수주 우선 수주"** 푸시. AI 가 "내부 재고 처분 기회" 를 외부 액션으로 변환.

- KBI ERP 는 기록만 함. 이 발상 안 해봤음
- "AI 가 영업과 생산을 연결" 메시지가 삼일PwC 가 팔기 좋은 서사
- 구현: 30 LOC (`GET /wip/dead-stock` + 대시보드 카드)

### Alt-3 (Phase 2 권장): 실사 자체를 AI 가 trigger

주 3-4회 실사 premise 가 무너진다면, **"지금 실사 돌리면 얼마 가치?"** 를 AI 가 답하게. 최근 run variance 누적이 임계치 넘으면 "이번 주 실사 권장" 푸시. **Premise 취약성을 feature 로 뒤집음**.

### 권장 조합: Alt-1 + Alt-2

Phase 1 에 대시보드 카드 2개만 얹기. 80 LOC 추가. 시연 가치 3x.

## 시연 스토리 재구성

### 현재 §12 문제

- 4단계 상태 전이는 임원이 2분 안에 까먹음
- "Listener auto-create", "reconciliation", "variance_m=-5" 기술 용어 침투
- "설비 하루 아낌" finale 에 금액 없음

### 재구성된 60초 스토리

> **Before**: "지난 분기 150SQ 드럼 생산할 때마다 평균 280m 씩 남았습니다. 1년 누적 4,800m. **자본으로는 670만원이 창고에서 잠자고 있었습니다.** 다음 수주가 들어와도 시스템이 이 재공의 존재를 몰랐기 때문에, **중복 생산으로 설비 17시간, 구리 1.2톤이 낭비됐습니다.**"
>
> **[시연]** 화요일 긴급수주 150SQ 280m. 화면에 **"기존 재공 300m 활용 가능 — 신규 생산 불필요, 설비 8시간 확보"** 표시. 클릭 한 번에 수주 처리.
>
> **After**: "AI 가 재공을 자본으로 추적하니, 같은 수주를 **설비 0시간, 구리 0kg** 으로 끝냈습니다. **영업팀엔 '잉여 재공 소진 가능 수주' 리스트가 매일 아침 도착합니다.**"

### 변경 포인트

1. **시작은 금액** — "670만원 잠자고 있다" 가 첫 문장. 기술 0
2. **Before/After 구조** — "지금은 어떻게?" 선제 답변
3. **Finale 은 영업 연결** — "생산 절약" 이 아닌 "영업이 잉여 소진"
4. **기술 용어 0** — reconciliation, listener, variance 제거

## 권장

**이대로 진행하지 말고 Phase 1 scope 에 2가지 추가 후 진입**:

1. **"유휴 자본" 대시보드 카드** (Alt-1). 50 LOC
2. **"Dead Stock → 영업 추천" 리스트** (Alt-2). 30 LOC
3. **시연 스토리 §12 전면 재작성** — Before/After + 금액 중심
4. **부분소진 간소 버전 (`wip_consumption_log` insert-only 테이블)** Phase 1 포함 — 시연 때 "20m 잔량 어떻게?" 질문 99% 확률. 밀면 시연 당일 망신. 50 LOC
5. **Premise 검증 필수**: 시연 전 KBI 현장 담당자에게 "주 3-4회 실사 가능?" 답 받기. 불가면 Alt-3 피벗 준비

### 수정된 Phase 1 총량

**약 370 LOC + 마이그 3 + 테이블 2 + UI 카드 2 + 다이얼로그 1**.
여전히 시연 기한 내 가능, 시연 가치 3x.

## What I noticed about how the designer thinks

### 강점

- **구조 우선 사고**: "listener 7지점 중앙화", "5대 Guard" — 개별 수정이 아니라 **invariant** 를 설계하는 본능. 회계사의 "복식부기 = 모든 거래 두 번 기록 invariant" 감각이 코드 아키텍처로 전이. System thinker.
- **회계 프레임 매핑 (§5)**: T1-T4 를 매출채권/매출실현/재고자산/매출원가에 대응시킨 건 **도메인 번역의 수재**. PoC 를 회계팀 언어로 재구성 가능한 사람.
- **Evidence-first (§2)**: file:line 박아놓은 건 말로 하지 않고 검증된 사실로 설계하는 직업적 훈련.

### 약점 / Blind spot

- **"옳은 설계" 에 도취되어 "팔리는 설계" 를 놓침**: §12 시연 스토리가 기술자 내러티브, "유휴 자본" 프레임 안 쓴 것, outbound 확장 안 떠올린 것 — "정확함" 이 "강력함" 보다 우선. PoC 는 반대.
- **보수적 premise 수용**: "주 3-4회 실사" 합의 받고 그 위에 설계 전체. **Premise 자체를 challenge 하는 본능 덜함**. 회계사는 감사 근거를 의심하기보다 정합시키는 훈련. Founder 는 반대 훈련.
- **제조 도메인 비경험 미세 노출**: "드럼 lot set-up 시간" 같은 **시간/가동률 기회비용** 이 설계 언어에 없음. 재공을 수량(m)으로만 보고 **생산 capacity 기회비용**으로는 안 봄.
- **"Phase 2 로 밀린 것이 시연 약점" 감각 덜함**: 회계사 훈련 = "완벽 못 하면 다음 분기". PoC = "시연 당일 충격 > 완벽".

### 종합

**"정확하고 구조적인 설계"** 에 탁월. 부족한 건 **"이걸 누구에게 얼마에 팔까"** 본능 — 훈련으로 붙는다. 이 리뷰의 역할은 그 근육 한 번 자극.
