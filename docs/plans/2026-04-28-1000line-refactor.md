### Monkeypatch 호환 패턴 (필수 — review 반영)

기존 테스트가 `monkeypatch.setattr(plan_pipeline, "<symbol>", mock)` 형태로
다음 심볼을 patch 한다 (검증된 path):

| Symbol                 | Patch path                                  | Test 파일                               |
| ---------------------- | ------------------------------------------- | --------------------------------------- |
| `auto_schedule`        | `plan_pipeline.auto_schedule`               | `test_schedule_route_overlap.py:37, 74` |
| `_execute_stage2_core` | `plan_pipeline._execute_stage2_core`        | `test_stage2_async_job.py:126`          |
| `compare_runs`         | `from ...plan_pipeline import compare_runs` | `test_stage1_update_versioning.py:177`  |

**규칙:** 위 심볼은 절대 sub-module 로 옮기지 않는다. `plan_pipeline.py` 의
모듈 namespace 에 함수 객체가 살아 있어야 monkeypatch 적용됨. 옮길 경우 반드시
`plan_pipeline.py` 가 attribute 로 re-bind 해야 한다:

```python
# plan_pipeline.py — re-export pattern
from app.presentation.routes._pipeline_shared import (
    _execute_stage2_core as _execute_stage2_core_impl,
)

# attribute 로 binding — monkeypatch.setattr(plan_pipeline, ...) 가 같은 이름 교체
_execute_stage2_core = _execute_stage2_core_impl
```

또한 sub-router 가 `_execute_stage2_core` 같은 patchable 심볼을 호출할 때는
**모듈 자체 import + attribute access** 패턴 사용 (`from X import Y` 가 아닌
`import X; X.Y(...)`):

```python
# plan_pipeline_stage2.py
from app.presentation.routes import plan_pipeline  # 모듈 자체 import

@router.post("/stage2", ...)
def run_stage2(body, db):
    run_label, base_date_dt, optimizer = plan_pipeline._parse_stage2_body(body)
    return plan_pipeline._execute_stage2_core(run_label, base_date_dt, optimizer, db)
```

이 패턴이 monkeypatch 적용 시점의 attribute 를 lookup 한다 — `from X import Y`
방식은 import 시점의 reference 를 fix 해 patch 무시.

```python
"""plan_pipeline 의 공유 helper 모듈 — _ai_cache singleton + Stage 2 helpers.

모든 sub-router (plan_pipeline_stage1/stage2/...) 가 이 모듈을 import 한다.
_ai_cache 는 모듈-레벨 dict 라 multiple import 가 동일 인스턴스를 참조 —
싱글톤 의미 보존.
"""

import logging
import threading
from datetime import datetime
from sqlalchemy.orm import Session

from app.infrastructure.database import SessionLocal

logger = logging.getLogger(__name__)

# AI 분석 결과 인메모리 캐시 — PoC 단계용 단순 dict
# key: run_label, value: {"status": "pending"|"done"|"error", "summary": {...}}
_ai_cache: dict[str, dict] = {}
_ai_cache_lock = threading.Lock()


def _run_ai_background(run_label: str) -> None:
    """백그라운드 스레드에서 AI 배치 요약을 생성하여 캐시에 저장한다.

    FastAPI BackgroundTasks 는 응답 전송 후 실행되므로, request-scoped DB
    세션이 이미 닫혀 있다. 따라서 SessionLocal() 로 독립 세션을 생성한다.
    """
    db = SessionLocal()
    try:
        from app.application.decisions.summarize_run import generate_batch_summary_sync

        result = generate_batch_summary_sync(run_label, db)
        with _ai_cache_lock:
            _ai_cache[run_label] = {"status": "done", "summary": result}
        logger.info("[AI Background] run_label=%s 분석 완료", run_label)
    except Exception as exc:
        with _ai_cache_lock:
            _ai_cache[run_label] = {"status": "error", "error": str(exc)}
        logger.warning("[AI Background] run_label=%s 분석 실패: %s", run_label, exc)
    finally:
        db.close()


def _start_ai_background(run_label: str) -> None:
    """AI 분석을 백그라운드 스레드로 시작한다 (캐시에 'pending' 마커)."""
    with _ai_cache_lock:
        _ai_cache[run_label] = {"status": "pending"}
    threading.Thread(target=_run_ai_background, args=(run_label,), daemon=True).start()


def _parse_stage2_body(body: dict) -> tuple[str, datetime | None, str]:
    """Stage 2 body → (run_label, base_date, parent_run_label) 파싱."""
    run_label = body.get("run_label", "")
    base_date_str = body.get("base_date")
    base_date = datetime.fromisoformat(base_date_str) if base_date_str else None
    parent_run_label = body.get("parent_run_label", "")
    return run_label, base_date, parent_run_label


def _execute_stage2_core(
    db: Session,
    run_label: str,
    base_date: datetime | None,
    parent_run_label: str,
) -> dict:
    """Stage 2 (자동 스케줄링) 핵심 실행 — DI shell.

    auto_schedule 은 import 시점에 plan_pipeline.py 에서 가져온다 (monkeypatch
    호환). 여기서는 늦은 import 로 cycle 회피.
    """
    from app.presentation.routes.plan_pipeline import auto_schedule

    return auto_schedule(
        run_label=run_label,
        db=db,
        base_date=base_date,
        parent_run_label=parent_run_label or None,
    )
```
