## 2. SpeedMaster 시드 데이터 실측값

### 2-A. 저압절연 (EX-B100)

- `setup_spec_min` = **60min** (전 SQ 동일)
- `setup_color_min` = 미설정 (default 0)
- `setup_compound_min` = 미설정 (default 0)

| 컬럼           | 매핑 교체 유형 | 시드값 | 참조값 | 일치 여부 |
| -------------- | -------------- | ------ | ------ | --------- |
| setup_spec_min | 규격교체       | 60min  | 60min  | **일치**  |

### 2-B. 저압시스 (SH-A100, SH-A120)

- `setup_spec_min` = **30min** (전 제품 타입 동일)
- `setup_color_min` = **120min** (전 제품 타입 동일)
- `setup_compound_min` = 미설정 (default 0)

| 컬럼            | 매핑 교체 유형 | 시드값 | 참조값 | 일치 여부                      |
| --------------- | -------------- | ------ | ------ | ------------------------------ |
| setup_spec_min  | 규격교체       | 30min  | 60min  | **불일치** (시드 30 < 참조 60) |
| setup_color_min | 색상교체       | 120min | 120min | **일치**                       |

> **주의**: 저압시스 규격교체 시간이 참조 기준(60min) 대비 시드 데이터(30min)에서 절반으로 설정되어 있다.
> 실제 schedule_optimizer.py에서는 setup_spec_min을 직접 사용하지 않고
> production_batch.setup_time_min(SpeedMaster.setup_spec_min에서 복사됨)을 사용하므로
> 이 차이가 스케줄링 결과에 반영된다.

### 2-C. 고압절연 (EX-CV1, EX-CV2)

- `setup_spec_min` = **300min** (전 SQ 동일)
- `setup_color_min` = 미설정 (default 0)
- `setup_compound_min` = 미설정 (default 0)

| 컬럼           | 매핑 교체 유형 | 시드값 | 참조값 | 일치 여부 |
| -------------- | -------------- | ------ | ------ | --------- |
| setup_spec_min | 규격교체       | 300min | 300min | **일치**  |

### 2-D. 고압시스 (SH-A150)

- `setup_spec_min` = **30min**
- `setup_color_min` = 미설정 (default 0)
- `setup_compound_min` = 미설정 (default 0)

| 컬럼           | 매핑 교체 유형 | 시드값 | 참조값 | 일치 여부                       |
| -------------- | -------------- | ------ | ------ | ------------------------------- |
| setup_spec_min | 규격교체       | 30min  | 120min | **불일치** (시드 30 < 참조 120) |

> **주의**: 고압시스 규격교체 시간이 참조 기준(120min) 대비 시드 데이터(30min)에서 1/4로 설정되어 있다.

### 2-E. 연선 (ST-T6B0, ST-54BO 등)

SpeedMaster에 **연선 공정 레코드가 존재하지 않는다.**
`_find_speed()` 함수에서 연선 장비(`ST-T6B0` 등)를 조회하지만,
시드 데이터에 `(ST-T6B0, "연선", SQ)` 키로 등록된 행이 없어
`setup_time`이 fallback으로 **0.0min**이 된다.

| 컬럼           | 매핑 교체 유형 | 시드값      | 참조값 | 일치 여부           |
| -------------- | -------------- | ----------- | ------ | ------------------- |
| setup_spec_min | 규격교체       | 0min (누락) | 240min | **불일치** (미등록) |
| (없음)         | 선재교체       | 0min (누락) | 120min | **불일치** (미등록) |

> **주의**: 연선 공정의 셋업 시간이 SpeedMaster에 전혀 등록되지 않아
> 규격교체 4시간, 선재교체 2시간이 스케줄에 반영되지 않고 있다.
> 61연선 코어의 경우 `_find_speed(speed_lookup, "연선", order, 35.0)` 호출에서
> `core_setup` fallback으로 210min이 하드코딩되어 있다.

### 2-F. 연합 (CA-12BO, CA-4BO, CA-LU)

SpeedMaster에 **연합 공정 레코드가 존재하지 않는다.**
`_find_speed()` 내 `equipment_map`에서 연합은 `["AS-A100"]`으로 매핑되어 있으나,
실제 EquipmentMaster의 연합 장비 코드는 `CA-12BO`, `CA-4BO`, `CA-LU`이며
SpeedMaster에 이들 코드로 등록된 행도 없다.

| 컬럼           | 매핑 교체 유형 | 시드값      | 참조값 | 일치 여부           |
| -------------- | -------------- | ----------- | ------ | ------------------- |
| setup_spec_min | 규격교체       | 0min (누락) | 120min | **불일치** (미등록) |

## 3. 컬럼 → 교체 유형 매핑 요약

| SpeedMaster 컬럼     | 의미               | 사용 위치                                                                     |
| -------------------- | ------------------ | ----------------------------------------------------------------------------- |
| `setup_spec_min`     | 규격(SQ) 교체 시간 | batch_grouping.py -> production_batch.setup_time_min -> schedule_optimizer.py |
| `setup_color_min`    | 색상 교체 시간     | schedule_optimizer.py (4-2 제약조건: 시스 공정에서 직접 DB 조회)              |
| `setup_compound_min` | 컴파운드 교체 시간 | 현재 코드에서 미사용 (스키마만 존재)                                          |
| `setup_start_min`    | 시작 셋업 시간     | 현재 코드에서 미사용 (스키마만 존재)                                          |

## 4. 불일치 요약 및 영향

| 공정     | 교체 유형 | 참조(min) | 시드(min) | 차이 | 스케줄링 영향               |
| -------- | --------- | --------- | --------- | ---- | --------------------------- |
| 연선     | 규격교체  | 240       | 0 (누락)  | -240 | 연선 공정 시간 과소 추정    |
| 연선     | 선재교체  | 120       | 0 (누락)  | -120 | 선재 교체 시간 미반영       |
| 저압시스 | 규격교체  | 60        | 30        | -30  | 시스 규격교체 시간 과소     |
| 고압시스 | 규격교체  | 120       | 30        | -90  | 고압시스 규격교체 시간 과소 |
| 연합     | 규격교체  | 120       | 0 (누락)  | -120 | 연합 공정 시간 과소 추정    |

> **결론**: 저압절연(60min)과 고압절연(300min), 저압시스 색상교체(120min)는 정확하게 일치한다.
> 연선/연합 공정은 SpeedMaster 데이터가 아예 누락되어 셋업 시간이 0으로 처리되고,
> 저압시스/고압시스의 규격교체 시간은 참조 기준보다 낮게 설정되어 있다.
> PoC 범위에서는 주요 병목 공정(절연, 시스 색상교체)의 정확도에 집중한 것으로 보인다.
