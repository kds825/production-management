목표: 30분 내 카드 사용법 + ⚠ 의견 보내기 + my-feedback 확인까지 학습.

---

## 1. 결정 카드란?

스케줄러가 자동으로 배치한 결과를 **자연어로 설명**하는 카드입니다. 간트 차트에서 작업 블록을 클릭하면 행 아래로 펼쳐집니다.

- **자연어** — 도메인 용어 그대로. "시스 3호기는 100~300SQ 시스 작업이 가능합니다 → 150SQ 적합"
- **6 섹션** — ❶ 왜 / ❷ 임팩트 / ❸ 앞·뒤 작업 / ❹ 설비 하루 / ❺ 묶음 비교 / ❻ 다른 후보
- **한 줄 요약** — 헤더에 ✓/⚠/· 마크로 의사결정 가능 여부 즉시 표시

## 2. 한 줄 요약(Verdict) 빠른 해석

| 마크   | 뜻                                 | 액션                           |
| ------ | ---------------------------------- | ------------------------------ |
| ✓ 정상 | 문제 없음                          | 다른 카드로 이동               |
| ⚠ 검토 | 색상교체 / 규격교체 / 납기 임박 등 | 펼쳐서 ❷ 임팩트 / ❸ 앞·뒤 확인 |
| · 일반 | 진행 보고                          | 필요 시 펼침                   |

## 3. ⚠ 의견 보내기 (가장 중요)

자연어가 어색하거나, 현장 운영과 다를 때 **그 줄 옆 [이상해요] 버튼** 또는 우측 상단 dialog 로 의견을 보냅니다.

1. ❶ 왜 섹션의 줄 우측 [이상해요] 클릭
2. dialog 가 뜸 — 어느 섹션 / 어느 줄(line_anchor)이 자동 입력됨
3. **본문 5000자 이내** — 예: "이 색상교체 추정이 어색합니다. 현장에선 같은 흑색 묶음 직후라 셋업이 거의 0인데 180분 잡힘"
4. **⌘+Enter** (Mac) 또는 **Ctrl+Enter** (Windows) 로 전송
5. **Esc** 로 취소

> 보내신 의견은 admin 큐에 모이고, 같은 line 에 여러 분이 의견 보내면 우선순위가 자동으로 올라갑니다.

## 4. 내 의견 history 확인

- topbar **🔔 bell** 아이콘 — 처리된 의견 건수 badge
- 클릭 → **/operator/my-feedback** 페이지
- status:
  - `접수됨` (open)
  - `검토 중` (investigating)
  - `✅ 반영됨` (fixed)
  - `검토 후 미반영` (wontfix) — 사유 자동 표시

## 6. 첫 1주 체크리스트

- [ ] 결정 카드 1건 펼쳐서 ❶~❸ 읽어보기
- [ ] 어색한 자연어 발견 → ⚠ 의견 1건 보내기
- [ ] 다음 날 my-feedback 들어가서 status 확인
- [ ] 같은 line_anchor 에 다른 운영자 의견이 묶이는지 (cluster) 관찰

## 7. 자주 묻는 질문

**Q. 의견을 보냈는데 답이 늦어요.**
A. SLA 목표 3일. 그 이상이면 admin 에게 직접 알려주세요. KPI 대시보드(/admin/kpi-dashboard) 에서 P50 SLA 가 추적됩니다.

**Q. 같은 의견을 다시 보내도 되나요?**
A. 네. 같은 line_anchor 의견은 cluster 로 묶여 우선순위 score 가 올라갑니다 — 운영자 N명 의견은 각자 카운트.

**Q. ?v2=0 이 뭔가요?**
A. v2 카드를 끄고 v1 (기존) 카드로 돌아가는 긴급 channel. URL 끝에 `?v2=0` 추가.

**Q. 첨부 파일은?**
A. 안정화 trial 1단계는 텍스트만. 첨부는 후속 spec.

## 8. dev 측 KPI (admin 만)

`/admin/kpi-dashboard` 에서 7 metric:

- Product: 카드 평균 검토시간, 카드 진입률
- Eng triage: Fix 비율, Fix SLA P50 (목표 ≤72h), line_anchor top 10

postmortem cadence: 매주 retro 에서 cluster top 10 / wontfix 사유 / SLA outlier 검토.
